# Сокращатель ссылок (URL Shortener)

Простой и удобный консольный сервис на Python для создания коротких текстовых кодов (алиасов) для длинных веб-ссылок. Проект выполнен в рамках учебного задания.

---

## Основная суть программы

Главная задача сервиса — избавить пользователя от громоздких и длинных URL-адресов, заменив их на компактные идентификаторы. Программа работает локально в оперативной памяти (In-Memory) на базе структуры данных «словарь» (`dict`), где ключом является короткий код, а значением — оригинальный URL.

**Принцип работы:**
> **Длинная ссылка:** `https://example.com/articles/python-basics-for-beginners`
> **Короткий код:** `py-base`
> 🔄 **Результат сохранения:** `py-base -> https://example.com/articles/python-basics-for-beginners`

---

## Функционал

В соответствии с техническим заданием, программа разделена на две части:

### Обязательная часть
* **Добавление новой ссылки:** связывает ваш длинный URL с коротким кодом, который вы вводите сами.
* **Проверка существования кода:** позволяет быстро узнать, занят ли конкретный короткий код.
* **Получение длинной ссылки:** мгновенно возвращает оригинальный URL по его короткому коду.
* **Вывод всех сокращённых ссылок:** отображает список всех сохранённых пар в формате `код -> ссылка`.

### Вариативная часть (Пункт 3)
* **Удаление ссылки:** возможность полностью стереть короткий код и связанную с ним ссылку из базы данных, если они больше не нужны.
